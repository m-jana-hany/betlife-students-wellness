# 🌿 Betlife — Early Web & Logic Prototype
(https://m-jana-hany.github.io/betlife-students-wellness/)
A lightweight interactive web application designed during an intensive 2-day summer camp hackathon to assist users with time management, sleep routine optimization, and daily schedule generation.

---

## 🎯 Problem Statement
Managing daily academic routines and sleep schedules is challenging for high school students. Lack of structured planning tools leads to irregular sleep cycles and reduced overall productivity.

---

## 💡 Key Features & Logic
* **Sleep Routine Guidance:** Informative modules highlighting health benefits and recommended sleep cycles based on age groups.
* **Dynamic Schedule Inputs:** Interactive form to collect user daily habits, class constraints, and flexibility preferences.
* **CLI Python Script Integration:** Backend logic prototype (`Betlife.py`) to process user information and validate schedule inputs.

---

## 🛠️ Skills & Technologies Applied
* **Front-End Development:** HTML5, CSS3, JavaScript (DOM Manipulation & Form Validation).
* **Scripting & Logic:** Python (CLI input processing and structured display).
* **Rapid Prototyping:** UI Layouting & Team Collaboration under a 48-hour time constraint.
